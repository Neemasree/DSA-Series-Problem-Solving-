## Standard Problem Format

Each problem should live inside its pattern folder:

```
Topic/
└── Pattern/
    └── problem-name/
        ├── solution.cpp
        └── README.md
```

Each README should record:
- Problem statement
- Pattern
- My thought process
- Brute force approach
- Optimal approach
- Time complexity
- Space complexity
- Key takeaway
