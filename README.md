## Problem Format

Every problem should follow this structure:

```
Topic/
└── Pattern/
    └── problem-name/
        ├── solution.cpp
        └── README.md
```

Each README should contain:

- Problem
- Pattern
- My thought process
- Brute-force solution
- Optimal solution
- Time complexity
- Space complexity
- Key takeaway

## Goal

- Build strong pattern recognition
- Revise problems pattern-wise for placements
- Keep my own solved solutions easy to find
- Understand **why** a pattern works, not just memorize code
